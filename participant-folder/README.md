# Telix Antigravity Workshop — Participant Folder

Welcome! This folder is your workspace for the workshop. **Three steps:**

1. Unzip this folder to your **Desktop** (keep the name `telix-antigravity-workshop`).
2. Open the **Antigravity** IDE → **File → Open Folder** → select `telix-antigravity-workshop`.
3. In the chat panel on the right, paste:

```
Run setup/preflight.sh and summarise the result in 3 lines. If anything FAILS, fix it.
```

You should see `READY FOR THE WORKSHOP`. If not, raise your hand.

## What is in here

| Item | What it is |
| :-- | :-- |
| `AGENTS.md` | Rules the agent follows automatically in this folder (EU-only, cite sources, no proprietary data). You do not need to edit it. |
| `PROMPTS.md` | Every prompt from the Participant Guide, ready to copy and paste. |
| `setup/preflight.sh` | The readiness check the agent runs in step 3. |
| `reports/` | Where the agent saves everything it produces for you today. |

## Two reminders

- Keep the model on **Gemini Flash (Low)**.
- Only **public** identifiers (gene symbols, UniProt accessions, compound names) go into prompts. No proprietary sequences, structures or patient data.
